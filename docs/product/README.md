# Product Documentation

This directory documents what the current product does and how it behaves.

Use it to record product-specific facts as they become real: domain concepts, features, business rules, workflows, permissions, limits, billing behavior, and technical decisions that belong to this application.

## Quick path

1. Create a focused document when a product responsibility needs durable shared context.
2. Describe verified current behavior, decisions, and constraints; do not invent future product rules.
3. Link related documents from this index when they become part of the product's working documentation.

## Boundary with engineering standards

| Documentation | Defines |
| --- | --- |
| [`../standards/README.md`](../standards/README.md) | How software is designed, organized, and maintained. |
| `docs/product/` | What this product does and how it behaves. |

Product documentation may change with the application. Engineering standards remain reusable and must not be changed to encode product-specific requirements.
